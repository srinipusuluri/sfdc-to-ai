## ✨ Features

- **Dark/Light Theme Toggle** — Switch between dark and light modes (persists in localStorage)
- **Interactive Progress Tracker** — 10-item checklist with progress bar (saves state in browser)
- **Search Bar** — Search across all sections by keyword
- **Scroll Animations** — Fade-in effects as you scroll through sections
- **Active Nav Highlighting** — Navigation highlights the current section as you scroll
- **Back to Top Button** — Smooth scroll to top
- **FAQ Accordion** — Expandable/collapsible FAQ section
- **Responsive Design** — Works on desktop, tablet, and mobile
- **Custom SVG Favicon** — Gradient chart emoji favicon in browser tab
- **140+ Online Resource Links** — All links open in new tabs

---

## 🛠️ Technologies Used

- **HTML5** — Semantic markup structure
- **CSS3** — Custom properties, gradients, animations, responsive media queries
- **JavaScript** — Vanilla JS for interactivity, localStorage for persistence, Intersection Observer for scroll animations
- **Font Awesome 6** — Icon library for visual enhancements
- **Google Fonts** — Poppins font family

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/srinipusuluri/claude-agentic-frameworks.git
   ```

2. Open the portal:
   ```bash
   open docs/index.html
   ```
   Or simply double-click `docs/index.html` in your file explorer.

No build tools or dependencies required — it's a single HTML file that runs in any modern browser.

## 💡 How to Use

1. **Start with the Skills section** — Familiarize yourself with what's in demand
2. **Follow the 6-Month Roadmap** — Each month has clear deliverables and resources
3. **Explore Resources** — Click through the 140+ learning links
4. **Check AI Tools** — Learn which AI tools can accelerate your learning
5. **Build Projects** — Use the project ideas and dataset links to build your portfolio
6. **Review Interview Questions** — Practice with 300+ curated questions
7. **Apply for Jobs** — Use the job portals and company links in the Jobs section
8. **Track Progress** — Use the interactive checklist to stay on track
