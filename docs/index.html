⚙️ ReAct — Reason + Act

Core Loop Pattern

ReAct interleaves reasoning (thinking steps) with actions (tool calls or environment interactions). Claude thinks, acts, observes the result, then thinks again — forming a tight feedback loop.

User Goal
→
Thought
What should I do?
→
Action
Call tool / API
→
Observation
Tool result
↺
Thought
What's next?
↑ Loop repeats until goal is complete ↑
Final Answer
←
Stop Condition
Goal met / max steps
💡 ReAct is the backbone of most Claude agent loops. It prevents hallucination by grounding each step in real observations rather than imagination.

Trace Example

T

Thought

"I need to find today's weather in Paris. I'll call the weather API."

A

Action

weather_tool(city="Paris")

O

Observation

{"temp": "18°C", "condition": "Partly cloudy"}

T

Thought

"I have the result. I can now answer the user."

✓

Final Answer

"It's 18°C and partly cloudy in Paris today."

🗺️ Planning Frameworks

Goal Decomposition

Rather than acting immediately, planning agents first decompose the goal into a structured plan, then execute steps — sometimes dynamically replanning when steps fail.

📋 Plan-and-Execute Pattern

1

Goal Intake

Receive high-level task from user

2

Planner

Decompose into ordered subtasks [T1, T2, T3…]

3

Executor

Run each subtask using ReAct + Tools

4

Replan (if needed)

If step fails → re-evaluate and update remaining plan

5

Synthesize

Aggregate results into final answer

🌳 Tree-of-Thoughts (ToT)

Explore multiple reasoning branches in parallel, evaluate each, and pick the best path.

💡 Dynamic replanning makes Claude resilient — if the world changes mid-task, it doesn't fail blindly; it reasons about the new situation.

📚 RAG — Retrieval-Augmented Generation

Memory & Knowledge Pattern

Instead of relying solely on trained weights, Claude retrieves relevant documents from a knowledge base at runtime, grounding answers in real data.

💡 Agentic RAG + Claude = Claude actively decides which documents it needs, queries multiple sources, and synthesizes cross-document insights.
